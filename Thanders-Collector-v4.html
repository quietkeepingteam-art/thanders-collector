📋 How to Get the Official Texas HHS Directory

  • 1
    Go to apps.hhs.texas.gov/providers/directories/al.xlsx — this downloads the current statewide Assisted Living provider directory directly, no login or manual search needed
  • 2
    Drag and drop the downloaded al.xlsx file into the import area on the left sidebar — the tool reads it directly and merges/deduplicates against your Google data automatically
  • 3
    The tool automatically filters to DFW-area cities as it imports, so it's fine that this file covers the whole state

Note: this directory covers Assisted Living facilities specifically. If HHS publishes a separate file for another care type (e.g. memory care) at a similar path under apps.hhs.texas.gov/providers/directories/, you can import that the same way — just drop it in and it merges in alongside the rest.

🔑 How to Get a Free Google Places API Key

  • 1
    Go to console.cloud.google.com and sign in with your Google account
  • 2
    Create a new project (e.g. "FrontPorchDFW")
  • 3
    Go to APIs & Services → Library and enable Places API (New)
  • 4
    Go to APIs & Services → Credentials → Create Credentials → API Key
  • 5
    Copy the key and paste it into the API Key field on the left
  • 6
    Free tier: Google gives you $200/month in free API credits. Each text search costs ~$0.017. Searching all 12 DFW cities × 4 care types = 48 searches ≈ $0.82 total. Well within the free tier.
